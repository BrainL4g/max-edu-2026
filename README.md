# SkillQuest

Игровое мини-приложение для студентов, помогающее развивать профессиональные навыки, находить подходящие образовательные курсы и готовиться к стажировкам.

## Основная идея

Пользователь проходит игровые задания, получает оценку своих навыков и персональные рекомендации по дальнейшему развитию.

## Основные возможности

- 🎮 Игровая диагностика и практические задания
- 📊 Карта навыков и прогресс
- 📚 Рекомендации образовательных курсов
- 💼 Подбор стажировок и практик
- 🤖 Взаимодействие через MAX

## Architecture

- Frontend — React + TypeScript
- Backend — Python + FastAPI
- Database — PostgreSQL
- Infrastructure — Docker
